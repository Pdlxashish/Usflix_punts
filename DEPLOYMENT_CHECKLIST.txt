# Deployment checklist

## Before deploying
[ ] Rotate any database, JWT, admin, or API key that was ever committed or pasted into docs.
[ ] Copy backend/.env.example to backend/.env for local development only.
[ ] Generate a new JWT secret with: node scripts/generate-jwt-secret.js
[ ] Choose a domain strategy:
    - Same-origin proxy: frontend and backend share one domain.
    - Split-origin: frontend and API are on different HTTPS domains.

## Backend on Fly.io
[ ] Install Fly CLI: https://fly.io/docs/flyctl/install/
[ ] Run: fly auth login
[ ] Run: cd backend
[ ] Run: fly launch --no-deploy
[ ] Create persistent storage: fly volumes create usflix_uploads --size 10 --region sjc
[ ] Set required secrets:
    fly secrets set DATABASE_URL="postgresql://user:password@host:5432/dbname?sslmode=require"
    fly secrets set JWT_SECRET="replace-with-strong-secret"
    fly secrets set ADMIN_USERNAME="admin"
    fly secrets set ADMIN_PASSWORD="replace-with-strong-password"
    fly secrets set FRONTEND_URL="https://your-frontend.example.com"
[ ] For split-origin auth cookies, set: fly secrets set COOKIE_SAME_SITE="none"
[ ] Deploy: fly deploy
[ ] Verify: curl https://your-fly-app.fly.dev/api/health

## Frontend
[ ] Cloudflare Workers: set VITE_API_URL only if API is on a different domain.
[ ] Deploy: npm run deploy:worker
[ ] Confirm the public frontend URL exactly matches backend FRONTEND_URL.

## Smoke tests
[ ] Home page loads.
[ ] Albums and featured content load.
[ ] Admin login works.
[ ] Upload a small image.
[ ] Restart/redeploy backend and confirm uploaded media still loads.
[ ] Browser console has no CORS or cookie warnings.
