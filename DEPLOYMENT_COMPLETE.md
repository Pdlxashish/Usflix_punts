## 🚀 Next Steps

### Step 1: Setup Environment (5 minutes)

**Windows:**
```powershell
.\scripts\setup-env.ps1
```

**Linux/Mac:**
```bash
chmod +x scripts/setup-env.sh
./scripts/setup-env.sh
```

This will:
- Generate a secure JWT secret
- Create `.env` files for frontend and backend
- Set up default configuration

### Step 2: Update Environment Variables (5 minutes)

Edit `backend/.env` and update:
```env
# Update with your actual database credentials
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/usflix

# Already generated for you
JWT_SECRET=<auto-generated>

# Update for production
FRONTEND_URL=http://localhost:8080
```

### Step 3: Test Locally (10 minutes)

```bash
# Start database
docker-compose up db -d

# Start backend
cd backend
npm run dev

# Start frontend (new terminal)
npm run dev
```

Visit http://localhost:8080 and verify everything works.

### Step 4: Choose Deployment Platform (2 minutes)

Pick one:

**Option A: Railway + Vercel** (Easiest - Recommended)
- Backend: Railway (with PostgreSQL)
- Frontend: Vercel
- Time: ~30 minutes
- Cost: ~$20-30/month

**Option B: Docker + VPS** (Most Control)
- Platform: DigitalOcean, AWS EC2, or similar
- Time: ~1-2 hours
- Cost: ~$10-20/month

**Option C: All Docker** (Local/Self-hosted)
- Platform: Your own server
- Time: ~30 minutes
- Cost: Free (your hardware)

### Step 5: Deploy! (30-60 minutes)

Follow the detailed instructions in **[DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)**


```bash
node scripts/generate-jwt-secret.js
```

```bash
# Backup database
docker-compose exec db pg_dump -U postgres usflix > backup.sql

# Restore database
docker-compose exec -T db psql -U postgres usflix < backup.sql
```

### Build for Production
```bash
# Build frontend
npm run build

# Build backend
cd backend
```

## ⚠️ Important Notes

### Security
- **Never commit `.env` files** to git (already in `.gitignore`)
- **Change default passwords** before deploying
- **Use strong JWT secrets** (generated by setup script)
- **Enable HTTPS** in production

### Performance
- **Use cloud storage** for production (AWS S3 or Cloudflare R2)
- **Enable CDN** for faster media delivery
- **Set up database backups** regularly
- **Monitor application** health

### Cost Optimization
- Start with Railway + Vercel (easiest)
- Move to VPS when you need more control
- Use Cloudflare R2 instead of S3 (cheaper)
- Enable caching to reduce bandwidth

## 🆘 Need Help?

### Common Issues

**"Cannot connect to database"**
- Check `DATABASE_URL` is correct
- Verify database is running
- Check network/firewall settings

**"JWT secret not set"**
- Run setup script: `.\scripts\setup-env.ps1`
- Or manually generate: `node scripts/generate-jwt-secret.js`

**"File uploads failing"**
- Check `UPLOAD_DIR` permissions
- Verify `MAX_FILE_SIZE` setting
- Check disk space

**"CORS errors"**
- Update `FRONTEND_URL` in backend `.env`
- Update `VITE_API_URL` in frontend `.env`
- Restart both servers

### Getting Support

1. Check [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md) troubleshooting section
2. Review error logs: `docker-compose logs -f`
3. Verify environment variables are set correctly
4. Check database connection
