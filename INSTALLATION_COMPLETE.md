### 🛠️ Managing the Servers

**To stop the servers:**
- Press `Ctrl+C` in each terminal window
- Or close the terminal windows

**To restart the servers:**
```cmd
# Backend (in one terminal)
cd backend
npm run dev

# Frontend (in another terminal)
npm run dev
```

**Or use the quick start script:**
```cmd
start-dev.cmd
```
