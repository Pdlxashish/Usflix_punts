# 🚀 Quick Start - New Features

## ✅ What's New?

Two new features are ready to use:
1. **⏰ Time Greetings** - Good morning/evening messages
2. **🎵 Our Playlist** - Songs with Spotify/YouTube embeds

---

## 🏃 Quick Start (3 Steps)

### Step 1: Start Backend
```bash
cd backend
npm run dev
```

Wait for: `✅ Database tables created/verified`

### Step 2: Add Content
1. Go to `http://localhost:5173/admin`
2. Click **"Romance"** tab
3. Click **"Time Greetings"** 🌙
   - Add a morning message: "Good morning, sunshine! ☀️"
   - Add an evening message: "Good evening, beautiful! 🌅"
4. Click **"Our Playlist"** 🎵
   - Add a song with Spotify URL
   - Click heart icon to set as "Our Song"

### Step 3: View Homepage
Go to `http://localhost:5173/` and scroll down!

---

## 🎵 How to Add Songs

### Get Spotify URL:
1. Open Spotify (web or app)
2. Find your song
3. Click "Share" → "Copy Song Link"
4. Paste in admin: `https://open.spotify.com/track/...`

### Get YouTube URL:
1. Open YouTube
2. Find your song
3. Copy URL from address bar
4. Paste in admin: `https://www.youtube.com/watch?v=...`

### Example Song:
- **Title:** Perfect
- **Artist:** Ed Sheeran
- **Spotify:** `https://open.spotify.com/track/0tgVpDi06FyKpA1z0VMD4v`
- **YouTube:** `https://www.youtube.com/watch?v=2Vv-BfVoq4g`
- **Memory:** "This was playing when we first met..."

## 💡 Pro Tips

### Time Greetings:
- Add 2-3 messages per time period (picks random one)
- Use emojis for personality
- Messages auto-update based on time

### Playlist:
- Add both Spotify AND YouTube for same song
- Click ♥ to set "Our Song" (only one)
- Click ✨ to set "Song of the Day" (only one)
- Memory notes show as italic quotes
