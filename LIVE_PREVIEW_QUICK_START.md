# Live Preview - Quick Start Guide

## 🎯 What's New?

The Live Preview feature now shows your **actual homepage** in real-time, making it easy to see exactly how your changes will look!

## 🚀 How to Use

### 1. Open Live Preview
- Go to the **Admin Panel** (`/admin`)
- Look for the **"Live Preview"** button in the bottom-right corner
- Click it to open the preview panel

### 2. View Real-Time Updates
The preview automatically shows:
- ✅ **Hero Banner** - Your featured content with carousel
- ✅ **Content Rows** - Media organized by categories
- ✅ **Time Together** - Live countdown of your relationship
- ✅ **Story Continues** - Dynamic statistics

### 3. Make Changes
Any changes you make in the admin panel update **instantly** in the preview:
- Upload new photos/videos → See them appear in content rows
- Edit branding text → Watch titles update live
- Change colors → See the theme change immediately
- Add hero banners → View them in the carousel
- Update relationship date → Time Together updates in real-time

### 4. Expand for Details
- Click the **maximize icon** (⛶) for full-screen preview
- Click the **minimize icon** (⛶) to return to compact mode
- Use the **external link icon** (↗) to open the actual site in a new tab

### 5. Close Preview
- Click the **eye icon** (👁) to close the preview
- The button returns to the bottom-right corner

## 💡 Pro Tips

### Best Practices
1. **Keep it open** while editing - see changes as you make them
2. **Use expanded mode** for detailed inspection
3. **Compare with live site** using the external link button
4. **Check all sections** - scroll through the entire preview

### What Updates Automatically
- ✅ Media uploads (photos, videos)
- ✅ Branding changes (text, colors, fonts)
- ✅ Hero banner edits
- ✅ Collection/category changes
- ✅ Relationship date updates
- ✅ Statistics (album/photo/video counts)

### Performance Tips
- The preview is **optimized** for smooth performance
- **Memoized components** prevent unnecessary re-renders

## 📱 Features

### Compact Mode (Default)
- **Size**: 380px × 600px
- **Position**: Bottom-right corner
- **Perfect for**: Quick checks while editing

### Expanded Mode
- **Size**: Full screen (with margins)
- **Position**: Center of screen
- **Perfect for**: Detailed inspection and verification

### Live Indicators
- **Green dot**: Shows real-time connection status
- **Footer stats**: Total memories and collections count
- **Carousel dots**: Current hero banner position

## 🎨 What You'll See

### Hero Section (Top)
- Featured banner with background image/video
- Title and subtitle text
- Carousel indicators (if multiple banners)
- Scroll indicator animation

### Content Rows (Middle)
- One row per category
- Up to 8 items per row (scrollable)
- Hover effects on media cards
- Category name and item count

### Time Together (Lower)
- Live countdown timer
- Years, months, days display
- Relationship start date
- Total days counter

### Story Continues (Bottom)
- Album count
- Photo count
- Video count
- Inspirational text

## 🔧 Troubleshooting

### Preview Not Showing
- **Check**: Is the admin panel loaded?
- **Try**: Refresh the page
- **Verify**: Browser console for errors

### Images Not Loading
- **Check**: Are media URLs correct?
- **Try**: Re-upload the media file
- **Verify**: File permissions and CORS settings

### Updates Not Appearing
- **Check**: Did the save operation succeed?
- **Try**: Close and reopen the preview
- **Verify**: Network connection is stable

### Performance Issues
- **Try**: Close other browser tabs
- **Check**: Clear browser cache
- **Verify**: System resources available
